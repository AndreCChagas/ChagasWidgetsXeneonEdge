## Português

Widgets do iCUE para a **CORSAIR XENEON EDGE**. Cada widget tem seus downloads na página de
**[Releases](../../releases)**, com a tag começando pelo nome do widget (ex.: `bluetooth-v0.1.1`).

### Widgets

| Widget | O que faz | Download |
|---|---|---|
| **Bluetooth** | Lista os dispositivos Bluetooth e liga/desliga o Bluetooth do PC e cada dispositivo com um toque | [Releases `bluetooth-v…`](../../releases?q=bluetooth&expanded=true) |

### Como instalar um widget

1. Abra o Release mais recente do widget e baixe:
   - o **Setup** do app companheiro (ex.: `BluetoothBridge-bluetooth-Setup.exe`), quando o widget tiver um;
   - o arquivo **`.icuewidget`**.
2. Rode o Setup. Ele instala sem pedir administrador, abre com o Windows, fica na bandeja e se atualiza sozinho.
   - Se aparecer **"O Windows protegeu o computador"**, clique em **Mais informações → Executar assim mesmo**.
3. No iCUE, vá em **Widgets**, clique no **+** e escolha o `.icuewidget`.

### Por que alguns widgets têm um app?

Widgets do iCUE rodam isolados e não acessam recursos do Windows, como o Bluetooth. O app companheiro faz esse
papel e só aceita conexões do próprio PC (`127.0.0.1`) vindas do widget no iCUE.

### Requisitos

- Windows 10 ou 11
- iCUE 5.47 ou mais novo
- CORSAIR XENEON EDGE

## English

iCUE widgets for the **CORSAIR XENEON EDGE**. Each widget ships in the **[Releases](../../releases)** page, with
tags starting with the widget name (e.g. `bluetooth-v0.1.1`).

### Widgets

| Widget | What it does | Download |
|---|---|---|
| **Bluetooth** | Lists Bluetooth devices and turns the PC's Bluetooth, and each device, on and off with a tap | [Releases `bluetooth-v…`](../../releases?q=bluetooth&expanded=true) |

### How to install a widget

1. Open the widget's latest Release and download:
   - the companion app **Setup** (e.g. `BluetoothBridge-bluetooth-Setup.exe`), when the widget has one;
   - the **`.icuewidget`** file.
2. Run the Setup. It installs without admin rights, starts with Windows, lives in the tray and updates itself.
   - If **"Windows protected your PC"** shows up, click **More info → Run anyway**.
3. In iCUE, open **Widgets**, click **+** and pick the `.icuewidget`.

### Why do some widgets have an app?

iCUE widgets run sandboxed and cannot reach Windows features such as Bluetooth. The companion app does that job
and only accepts local connections (`127.0.0.1`) coming from the widget inside iCUE.

### Requirements

- Windows 10 or 11
- iCUE 5.47 or newer
- CORSAIR XENEON EDGE
